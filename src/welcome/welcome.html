Jira Timesheet Viewer

Search what's assigned to you in Jira for any date range, and see what you've already logged on each day — without leaving the browser. This reads worklogs, it doesn't create them: logging time still happens in Jira itself, one click away.

1. Create a Jira API token

  1. Go to id.atlassian.com → Security → API tokens.
  2. Create a token and copy it — you won't be able to see it again.

2. Connect

  1. Click the extension icon in your browser toolbar.
  2. Enter your Jira base URL (e.g. https://your-domain.atlassian.net), your e-mail and the API token.
  3. Click Connect.
This is never written to disk.

Your base URL, e-mail and API token are kept in the browser's memory-only session storage for as long as this browser window stays open. They are never synced, never sent anywhere except directly to your own Jira site, and disappear the moment you close the browser — at which point you'll be asked to connect again.

Tip: keep the token in your password manager

The extension itself never saves this — that's deliberate. But you can save time by keeping it in a password vault of your own:

  • Your browser's own password manager might offer to save it after you click Connect (look for a "Save password?" prompt, or a key icon in the token field next time). This isn't guaranteed to trigger inside an extension popup — try it and see.
  • Third-party managers (1Password, Bitwarden, etc.) can't autofill directly into this form — Chrome doesn't let one extension reach into another extension's page. Instead, save the base URL, e-mail and token as a regular entry in your vault, then copy and paste them here when asked. Since you only reconnect once per browser session, this is rarely needed.

3. Find your items

  1. Click Open My Items to open the side panel.
  2. On the small calendar, click a start day and an end day to set your period. The search always brings back everything assigned to you in that window, due date or not.
  3. (Optional) Click Projects, below the calendar, to narrow the search to one or more projects — checkboxes, more than one at a time. Leave everything checked to search across all of them. Unlike the two filters below it, this one changes the search itself, not just what's shown.
  4. The list below fills in, grouped by the day you logged time — each day shows the issues you worked on, the hours, and the worklog's description underneath, if you wrote one. Days with nothing logged show up too, instead of disappearing.
  5. (Optional) Click Status, below Projects, to narrow the list you already have to one or more statuses — this doesn't search Jira again, it just re-shows what's already there.
  6. (Optional) Type in the search box below Status to narrow the list further by key or summary — also without searching Jira again.
  7. At the bottom, Not logged in this period lists everything assigned to you in that window with no worklog at all — the things that still need a Log work entry.
  8. Click any issue to open it on your Jira site, in a new tab (reused for the next issue you click) — that's where you use Log work as usual.
  9. (Optional) Click Open summary in new tab, below all the filters, for a plain read-only report of the same day-grouped list in its own browser tab — no empty days, no "Not logged" section, just what actually has time logged against it. Handy for copying, reviewing or printing outside the narrow side panel.

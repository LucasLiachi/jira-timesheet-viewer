v1.0.0

First stable release.

  • Two independent search areas: Timesheet (search by date range, worklogs grouped by day) and My Items (search by date range and project, with status, issue type and text filters).
  • Worklog descriptions shown alongside logged hours, and a trailing list of issues with nothing logged in the period.
  • Read-only summary of the current results, opened in a new tab for copying or printing.
  • Connection stored in memory only by default; optional encrypted persistence across browser restarts via "Stay connected on this device".
